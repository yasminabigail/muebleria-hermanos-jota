# 🪑 Mueblería Hermanos Jota - E-commerce

## 📖 Descripción

Mueblería Hermanos Jota es una plataforma e-commerce interactiva del lado del cliente, desarrollada para simular una experiencia de compra completa sin conexión a un backend. El proyecto utiliza el manejo de datos locales para representar el catálogo, el carrito de compras y las interacciones principales del usuario.

## 🛠️ Tecnologías Utilizadas

- **HTML5 semántico:** estructura accesible y organizada para las distintas páginas de la tienda.
- **CSS3:** diseño responsive con enfoque **Mobile First** y uso de **Flexbox** para la composición de los elementos.
- **JavaScript Vanilla:** manipulación del DOM, asincronismo simulado con `async/await` y persistencia de datos mediante `localStorage`.

## 🛒 Funcionalidades Principales

- Carga dinámica del catálogo de productos.
- Carrito de compras funcional con actualización de cantidades y persistencia local.
- Validación del formulario de contacto con prevención del envío predeterminado.
